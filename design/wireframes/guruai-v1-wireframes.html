Type

Baloo 2 for child-mode buttons and names, Mukta for letter cards, captions and all parent text. Both are by Ek Type (Mumbai), drawn with Devanagari and Latin as one design, and both are on Google Fonts under the Open Font License, so they can be bundled in the app for offline use. Baloo 2 is round and heavy, which keeps a two-word button readable for a new reader at 30 to 32 dp. Mukta has plain, textbook-like letter shapes and seven weights, so it suits both a 140 dp letter a child is learning to recognise and 14 dp helper text for a parent. Devanagari needs room above and below the line for matras, so line height is 1.3 for display sizes and 1.5 for reading sizes.

Icons for children who cannot read

  1. Every child-facing action has an icon and a spoken line from Shekru. Text is a third channel, for the adult beside the child.
  2. One meaning per icon across the app, and one main action per screen.
  3. State is never colour alone: it changes shape as well (dashed outline to filled disc, plain edge to thick edge plus badge).
  4. Solid shapes, 3 dp strokes, 32 dp or larger in child mode. Parent mode uses 24 dp outline icons with a text label.
  5. No red, no cross and no "wrong" sound in child mode. A miss is a hint.
  6. No links out of the app, no ads, no text-only controls in child mode.

Flow map

First run (parent, 3 screens, about 1 minute)

Welcome→Parent lock→Who is learning→Hand over: mic permission→Child picker
  • The model and starter packs start downloading in the background when the app first opens (Welcome); the child's packs follow after "who is learning". Not finished at hand-over → Shekru is getting ready → download done → turns into the queue by itself
  • Storage short → Storage prompt → fewer packs → download continues
  • Parent lock → "use a separate GuruAI PIN" (or a phone with no screen lock) → PIN set and confirmed on the same screen
  • Mic permission refused or skipped at the hand-over → the child sees Ask a grown-up; parent home offers the way back to the prompt
  • Goodbye after the first lesson → "For parents" strip → parent gate → Help improve Shekru?. The same question shows on the next parent-mode open and on the setup card until answered
  • Everything skipped (board, goals, style, lessons per day, consents, more children) → "Finish setting up" card → Child profile form

Daily session (child)

App opens→Child picker→Today's queue→Lesson→Lesson finished→Queue, next stop→…→Goodbye
  • Inside one answer: Teach (word items: Marathi-led or English-led) → Ask → Listening → Correct → next item
  • Every third correct answer in a row (3, 6, 9 ...) → Streak praise, unless a comeback or after-a-hint line takes precedence
  • Between two items, at random, at most one per lesson and not in every lesson → Surprise moment → next item
  • Miss → hint: picture word for a letter, Marathi bridge for a word → Listening → miss again → Reveal and repeat → next item
  • Nothing heard or unsure → Say it again → Listening. A second time in a row: teaching moves on; in the quiz it is a missed try and gets the hint
  • Right meaning in Marathi or Hindi on an English-target item → acknowledged ("हो, सफरचंद!" or "हो, अर्थ बरोबर!"), then the bridge step; not a wrong attempt, not correct
  • Right meaning in Hindi on a Marathi-target item → Praise, follow-up question → knows it: next item; does not: Word modelled
  • Pause, Home or a call → Paused → continue: same answer; stop: Queue
  • App killed → Child picker → Queue → same answer
  • Daily lesson goal met (a lesson counts when it reaches its end; revision never counts) → Goodbye. Active-time cap reached mid-lesson → the lesson finishes → Goodbye

Parent mode: entry and exit

Any child screen→Hold lock 2 s→Phone's unlock sheet or GuruAI PIN→Parent home→Assign Report Settings
  • GuruAI PIN mode, wrong PIN → Wrong → 3 wrong: 30 s wait → 3 more: 5 min wait → every further 3: 15 min wait. Fingerprint or face opens it at any time
  • Exit: "मुलाकडे द्या" button, or 2 minutes without a touch (warning), or app to background → Child picker
  • Settings → a child's row or "add a child" → Child profile form · Settings → Downloads → Downloads · Settings → Parent lock

When Shekru cannot listen

  • Model missing or download failed, switch off → child sees Shekru is getting ready; the lesson waits. Parent → Parent home banner → resume the download, or turn on the switch → Lesson with answer buttons
  • Mic refused or skipped at the hand-over, switch off → child sees Ask a grown-up. Parent → Parent home banner → one tap back to the permission prompt, or the switch
  • Phone too weak (first-use check) → child sees Ask a grown-up, weak phone. Parent → Parent home banner → the switch; noted in the session summary
  • Switch on → no buttons while Shekru speaks → buttons during the answer turn → stays on for the rest of the session, through pauses and calls → off at goodbye, Stop or app closed
  • Consent switched off → Settings: uploads stop at once

D. Decisions and open questions

The gaps raised in the first round, each with the owner's decision. Numbers are unchanged, so "Decisions 9" in a frame note is item 9 here. The three questions that were open after round 3 (parent lock, mic timing, Hindi answers) were decided on 2026-11-20 and are folded into items 1, 2, 10 and 24. Two points that came up while drawing those decisions were decided the same day and are items 25 and 26. Nothing is open.

  1. What unlocks a locked PIN?

    Superseded. Decided 2026-11-20: there is no "locked" state. The parent lock is the phone's own screen lock by default, with an optional separate GuruAI PIN. In PIN mode the waits are 30 s, 5 min, then 15 min for each further 3 wrong, never longer, and fingerprint or face opens the gate at any time (the phone's pattern does not). The earlier answer, a 24-hour lock, is withdrawn.

  2. How many wrong PINs move between lockout stages?

    Decided 2026-11-20: GuruAI PIN mode only. 3 wrong: 30 s. 3 more wrong: 5 min. Every further 3 wrong: 15 min. A correct PIN, or fingerprint or face, resets the count. In phone-lock mode Android handles wrong attempts itself.

  3. Child picker and "no switching to a sibling"

    Decided 2026-11-19: the stated default stands. The picker shows at every app open, even with one child. Once a child is in, the only ways back are closing the app or the parent gate.

  4. Telling siblings apart without reading

    Decided 2026-11-19: a fixed picture set (animals) in M1; a picture in use is unavailable to siblings. The child's own photo (camera or gallery, cropped to the round icon, kept on the phone) is a future option recorded in the PRD.

  5. What earns a star, and the first day

    Decided 2026-11-19: the stated default stands. One star per finished trail stop (lesson or revision), never taken away. On day one the star is an empty outline with 0. Nothing to spend stars on in M1.

  6. The "optional limit" on language style

    Decided 2026-11-19: the stated default stands. A tick box "हीच शैली कायम ठेवा" locks the starting style; without it the level may change between sessions.

  7. Daily minutes choices

    Obsolete. Decided 2026-11-19: the daily goal is a number of lessons (1 to 5, default 3), with an active-time safety cap (default 30 minutes, can be changed or turned off). The cap chips in the profile form (20, 30, 45, no limit) are kept.

  8. After the daily goal is met

    Decided 2026-11-19: the stated default stands, now for the lesson goal instead of minutes. The goodbye screen has no start button; reopening the app that day shows goodbye again; nothing can be replayed.

  9. "Parent helps" buttons are on the child's screen

    Resolved. Decided 2026-11-19: the buttons appear only while a parent has the "मी उत्तरं तपासेन" switch on. The switch sits on parent home behind the parent lock and is per child. It stays on for the rest of that session (one sitting: from the child tapping their face to goodbye, Stop or the app being closed; a pause or call does not end it) and is off again afterwards. Mic and judge are off while it is on, and taps update mastery. The start sheet that let anyone start a parent-helps lesson from the child side is removed.

  10. Mic permission

    Decided 2026-11-20: the mic permission is asked when the parent taps "hand the phone to your child", so the adult answers the Android dialog. If it was refused or skipped, the child sees "ask a grown-up" and parent home offers a one-tap way back to the prompt (or the app's page in the phone's settings when Android no longer shows the dialog). The earlier answer, at the child's first listening turn, is withdrawn.

  11. Child echoes the prompt word

    Decided 2026-11-19: the stated default stands. No new engine rule: the prompt word is excluded from that turn's answers, so an echo is a miss and gets the hint. "Didn't hear" is asked once; a second in a row moves on (PRD).

  12. Consent defaults and skipping

    Changed. Decided 2026-11-19: consent is not an onboarding step. It is first offered on the goodbye after the first lesson, through a "For parents" strip that opens the parent gate and then the consent screen; it also shows on the next parent-mode open and as a setup-card row until answered. Two switches, both off by default; "Not now" leaves both off.

  13. Auto-return details

    Decided 2026-11-19: the stated default stands. A 10 s warning with "इथेच थांबा" before the 2-minute return. The return lands on the child picker, or on the paused lesson if the gate was opened from a lesson.

  14. Assigning more than fits today

    Decided 2026-11-19: the stated default stands, now counted in lessons. Assigned lessons go first in today's queue; one that does not fit in the daily lesson goal comes first tomorrow. No date picker.

  15. How a deletion request travels in M1

    Decided 2026-11-19: the stated default stands. A Settings row "पाठवलेली रेकॉर्डिंग पुसायला सांगा" shows the device code and sends the request through the upload function.

  16. Class names and pre-primary

    Decided 2026-11-19: the stated default stands for class names: नर्सरी, ज्युनिअर केजी, सीनिअर केजी, पहिली, दुसरी. The board part is obsolete: board is no longer asked in onboarding; it defaults to Maharashtra State Board and is changed in the profile form.

  17. Finishing onboarding without the download

    Decided 2026-11-19: the phone can be handed to the child before the download finishes. The model starts downloading on first open, so this is the less common case. Lessons then wait: the child sees "Shekru is getting ready, ask a grown-up", which turns into the normal queue by itself when the download completes, or a parent turns on the switch.

  18. Lesson screen additions

    Decided 2026-11-19: the stated default stands. Item dots under Shekru, the lock top left, and a 64 dp pause button stay. The lock icon is deliberately low-key (2.42:1), recorded as a known limit in the tokens.

  19. Digits in parent mode

    Decided 2026-11-19: the stated default stands. Latin digits in Marathi parent text; Devanagari digits only inside lessons that teach them.

  20. New spoken lines

    Decided 2026-11-19: the stated default stands: the listed lines are to be voiced. Added since: the "ask a grown-up" lines (model, mic, weak phone), "मी तयार!", the letter hint, the two bridge acknowledgements "हो, सफरचंद! इंग्लिशमध्ये?" and "हो, अर्थ बरोबर! इंग्लिशमध्ये?", and the streak, surprise and two lesson-finished lines.

  21. Letter shapes in the chosen fonts

    Decided 2026-11-19: Mukta for letter cards and Baloo 2 for child buttons stand. The check of ल, श, झ, ण and अ against the Balbharati forms on a real phone is still to be done before lock-in.

  22. Report contents

    Decided 2026-11-19: the stated default stands, with minutes replaced by lessons finished against the daily goal: days and lessons this week, letters mastered, next-day revision result, "needs practice" letters, last three lessons.

  23. Parent home: section order

    Decided 2026-11-19: the stated default stands. The PRD order: Up next, Pending, Revision due, Completed. A "waiting for download" section appears between Up next and Pending only when a lesson's pack is missing.

  24. Hindi answers

    Decided 2026-11-20: a Hindi answer with the right meaning counts as correct only on Marathi-target items, where the follow-up asks for the Marathi word. On an English-target item a right meaning in Marathi or Hindi gets the bridge step ("हो, सफरचंद! इंग्लिशमध्ये?" or "हो, अर्थ बरोबर! इंग्लिशमध्ये?"), is not a wrong attempt and is not counted as correct. Shekru never repeats the Hindi word. Reflected in the PRD (Language design 7 and 8).

  25. The phone's screen lock is removed after setup

    Decided 2026-11-20: if the parent chose the phone's screen lock and later turns that lock off in Android, the next long-press says the phone has no lock and asks the parent to set a GuruAI PIN before parent mode opens. Reflected in the PRD (Edge Cases).

  26. "Only this time" on the mic dialog

    Decided 2026-11-20: the mic banner on parent home tells the parent to choose "While using the app". "Only this time" ends when the app is closed, so the permission would be missing again the next day. Reflected in the PRD (Edge Cases).
