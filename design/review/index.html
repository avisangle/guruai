What to look for

  1. Which one would a 5-year-old want to see every day?
  2. In Listening, is it obvious that it is now the child's turn to speak?
  3. Does Try again feel gentle and encouraging, never sad?
  4. While it talks, does the mouth help show the sounds?
  5. Does it still read clearly at 64 px, the size of a small icon?
